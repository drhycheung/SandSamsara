## 开篇声明 & 创作溯源

本项目《沙界轮回 / Sand-Samsara》是对 2005 年经典粒子沙盒《Hell of Sand》的现代艺术再演绎。本作融入轮回与业力的哲学意象作为纯艺术创作，并非正统佛教教义复刻，不具备宗教参考价值。游戏本体无任何文字剧情，本篇说明仅为感兴趣的读者提供背景补充。

## 世界观叙事（最终定稿）

这里是沙界，一座由微尘与粒子构成的无名世间。

所有众生于此苏醒，无前世记忆，不知轮回，不解因果。他们或麻木游荡、或躁动奔波、或拼命避苦求生、或执着寻觅世界边界、渴求永恒。众生一切奔跑、逃避、挣扎，皆为无明驱使——试图依靠改变外境获得安宁，却始终无法脱离流转的命运。

世间潜伏着火之业轮，象征众生交织聚集的共恶业。

业轮现世，可随玩家牵引游走，亦可自行遍历世间。但凡众生被业力牵引卷入轮中，便会纠缠入集体业力之内。卷入者越多，共业越重，业轮随之愈发庞大。

随着业轮膨胀，无数众生被缓缓挤压至世界边缘，烈焰滋生、四面封堵。众生穷尽逃亡，却无处可避。当共业累积至极致、业轮抵达临界极限，世界便会因业力成熟而自然崩坏。

烈焰席卷天地，粒子溃散、山河焚毁，一期世间彻底终结。

毁灭并非惩罚，而是因缘聚合的必然结果。共业成熟，则世界坏灭；坏灭之后，世间沉寂重置，新一轮懵懂众生再度降生，轮回继续往复。

于此无尽流转之中，绝大多数众生随业浮沉、徒劳挣扎、随坏而灭。

唯有极少数人，放下恐惧、放下求生、放下执着，心安不动。不逃、不执、不逐外境，心念清净，便会触发飞升。金身显、光点环绕、脱离尘界、向上出离，彻底断除此世轮回，不再重来。

玩家为世间旁观者，可撒沙、布火、造境、牵引业轮，成为因缘之一。

你可以干预境遇，但无法主宰因果；你可以创造外缘，但无法替众生解脱。

一切浮沉、毁灭、出离，皆由无数因缘和合而成，万般命运，只可随缘。

游戏本体无任何文字剧情，遵循禅宗「不立文字」，一切深意，交由观者自悟。

## 操作一览

| 操作 | 效果 |
|------|------|
| 左键点击／拖动空白处 | 绘制当前所选元素（沙、水、火、岩浆、油、石、火药、灰烬、植物） |
| 左键按住火柴人 | 牵引该众生，松开后其短暂眩晕 |
| 左键按住火之业轮 | 拖拽业轮；松开后业轮恢复自主游走 |
| 右键（按住拖动） | 剪除植物（化为灰烬） |
| 顶部工具栏 | 切换元素、调节画笔粗细、清空世界、手动召唤业轮 |

## 运行与部署说明

### 本地快速运行（零配置）

本项目为纯静态单文件网页，无后端、无依赖、无需编译。下载项目全部文件后，直接双击根目录下的 `index.html` 文件，即可用默认浏览器打开游玩，支持所有主流浏览器。

### Web 服务器部署方式

可部署至任意静态网页服务器，包括 GitHub Pages、Vercel、Nginx、Apache 等。只需将项目所有静态文件直接上传至网站根目录，无需额外配置，访问对应域名/地址即可在线游玩。
