## 开篇声明 & 创作溯源

本项目《沙界轮回 / Sand Samsara》是对 2005 年经典粒子沙盒《Hell of Sand》的现代艺术再演绎。本作融入轮回与业力的哲学意象作为纯艺术创作，并非正统佛教教义复刻，不具备宗教参考价值。游戏本体无任何文字剧情，本篇说明仅为感兴趣的读者提供背景补充。

## 世界观与玩法

本作是一款下落粒子沙盒艺术作品，构筑了沙界——一方由微尘与粒子凝聚而成的无名世间。玩家并非单纯的旁观者，而是世间的一缕外缘：一面挥洒沙、火、水、岩浆等各类物质，干预世间境遇；一面静观无数火柴人众生在轮回中的浮沉际遇。所有众生于此懵懂降生，无前生记忆、不识轮回、不解因果。众生心性各异：或麻木游荡、浑噩度日；或躁动不休、漫无目的奔波；或疲于奔命、竭力规避苦痛；或执念深重、执着探寻世界边界、渴求永恒存续。一切逃避、挣扎与追逐，皆源于无明痴执，众生妄图借改变外在境遇求得安宁，却始终困于往复流转的宿命之中——单纯避苦求生，永远无法抵达真正的解脱。

此方世间潜藏火之业轮，是众生交织累积的共恶业具象化身。业轮可随玩家拖拽牵引，亦可自主遍历世间，但凡众生被其引力卷入，便会缠入集体业力之中。卷入的众生越多，共业羁绊越重，业轮体量便随之不断膨胀壮大。

随着业轮持续扩张，被困众生会被逐步挤压至世界边缘，边界烈焰滋生、四面封堵，令众生无处遁形。当共业累积至临界点、业轮抵达极限体量时，成熟的业力便会引发世间崩坏。烈焰席卷全域，粒子溃散、境貌焚毁，这一期的沙界世间就此终结。

世间毁灭并非惩戒，而是因缘聚合的必然规律。共业成熟则世界坏灭，沉寂过后，世间重置新生，新一轮无知众生再度降生，无记忆、无过往，开启新一轮轮回往复。

在无尽的轮回流转中，绝大多数众生皆随业浮沉、徒劳挣扎，最终随世间崩坏湮灭。唯有极少数心性通透者，能放下恐惧、求生执念与一切向外追逐的躁动，安住本心、寂然不动。心念清净无执之时，便会触发殊胜飞升：身形化作金辉、周身光点环绕，缓缓升腾脱离尘界，彻底斩断此方轮回，永不复返。这般解脱极为稀有，多数轮回之中，甚至无一众生得以出离。

玩家可干预世间、造境塑形、牵引业轮，成为万千因缘中的一环，但无法主宰结局、掌控众生因果。每个众生皆有自身业力与宿命，玩家的干预仅为外在缘法，既不能替众生觉悟解脱，也无法指定任何人飞升出离。所有命运、浮沉、毁灭与超脱，皆由无数因缘和合而成，万般际遇，只可随缘。

游戏本体全程无任何文字剧情、提示与旁白说教，严格恪守禅宗「不立文字」的核心思想，让玩家纯粹通过观察体悟世界规律与哲思。本篇 README 文字说明仅作为外部补充，专门留给有兴趣的读者深入了解项目创作背景与世界观内核，不属于游戏体验的一部分。

## 操作一览

| 操作 | 效果 |
|------|------|
| 左键点击／拖动空白处 | 绘制当前所选元素（沙、水、火、岩浆、油、石、火药、灰烬、植物） |
| 左键按住火柴人 | 牵引该众生，松开后其短暂眩晕 |
| 左键按住火之业轮 | 拖拽业轮；松开后业轮恢复自主游走 |
| 右键（按住拖动） | 剪除植物（化为灰烬） |
| 触屏设备 | 单指触摸等同左键：绘制元素、牵引众生或拖拽业轮；画面与按钮自适应手机／平板 |
| 顶部工具栏 | 切换元素、调节画笔粗细、清空世界、手动召唤业轮 |

## 运行与部署说明

### 本地快速运行（零配置）

本项目为纯静态单文件网页，无后端、无依赖、无需编译。下载项目全部文件后，直接双击根目录下的 `index.html` 文件，即可用默认浏览器打开游玩，支持所有主流浏览器。

也可以使用 Python 在项目根目录启动一个简易本地服务器：

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000` 即可游玩，按 `Ctrl+C` 停止服务器。同一局域网内的其他设备可通过 `http://<本机IP>:8000` 访问。

### GitHub Pages 部署

本项目已通过 GitHub Pages 在线部署：**<https://drhycheung.github.io/SandSamsara/>**

如需自行部署一份：

1. 将本仓库 Fork 至你的 GitHub 账号，或推送你自己的副本
2. 进入仓库页面，依次打开 **Settings → Pages**
3. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**
4. **Branch** 选择 `master`（或 `main`），目录选择 `/ (root)`，点击 **Save**
5. 等待 1–2 分钟构建完成，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

### Vercel 部署

1. 登录 [Vercel](https://vercel.com)，点击 **Add New → Project**
2. 导入本项目的 GitHub 仓库
3. 保持默认配置（Framework Preset 选择 **Other**），直接点击 **Deploy**
4. 部署完成后即可通过 Vercel 分配的域名访问，亦可按需绑定自定义域名

### Nginx / Apache 部署

将项目全部文件上传至服务器站点根目录，无需任何额外配置：

- **Nginx**：放置于 `/usr/share/nginx/html/`（或你自行配置的 `root` 目录）
- **Apache**：放置于 `/var/www/html/`
