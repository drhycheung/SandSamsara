## 开篇声明 & 创作溯源

本项目《沙界轮回 / Sand-Samsara》是对 2005 年经典粒子沙盒《Hell of Sand》的现代艺术再演绎。本作融入轮回与业力的哲学意象作为纯艺术创作，并非正统佛教教义复刻，不具备宗教参考价值。游戏本体无任何文字剧情，本篇说明仅为感兴趣的读者提供背景补充。

## 游戏简介

这是一个下落粒子沙盒游戏。玩家如同观察者，可以挥洒沙、火、水、岩浆等种种物质，观察世界之中无数火柴人众生的际遇。

众生在此世界苏醒，不带过往记忆。

一部分人浑浑噩噩度日；一部分不停躁动游荡；一部分拼尽全力躲避灾祸以求生存；还有一部分执着地想要寻找世界的边界，渴求逃离与永生。

但仅仅逃避苦难、拼命求生，并不能带来真正的解脱。

世界会周期性降临「火之轮」，绝大多数众生会被焚毁，记忆彻底抹除，新一轮的生命再次诞生于此，循环往复。

只有极少数众生，放下躁动、恐惧与向外追逐的执念，安住不动，才有可能触发飞升：化作金色光体向上升腾，彻底离开这片沙之世界，不再参与轮回。

解脱极为稀有，多数轮回之中，甚至不会出现一位解脱者。

**玩家可以干预世界，撒下种种境遇，成为众多因缘之中的一环，但无法掌控最终结果。**

一切结局来自无数条件的因缘聚合。每一个众生自有其自身的因果倾向，玩家只是其中一个外缘，不能全权决定众生的命运，结局只可随缘。

玩家可以造险，也可以创造安宁的环境，但无法直接指定谁获得解脱。觉悟只能来自众生自身心念的转变。

## 世界观叙事

这里是沙界，一座由微尘与粒子构成的无名世间。

所有众生于此苏醒，无前世记忆，不知轮回，不解因果。他们或麻木游荡、或躁动奔波、或拼命避苦求生、或执着寻觅世界边界、渴求永恒。众生一切奔跑、逃避、挣扎，皆为无明驱使——试图依靠改变外境获得安宁，却始终无法脱离流转的命运。

世间潜伏着火之业轮，象征众生交织聚集的共恶业。

业轮现世，可随玩家牵引游走，亦可自行遍历世间。但凡众生被业力牵引卷入轮中，便会纠缠入集体业力之内。卷入者越多，共业越重，业轮随之愈发庞大。

随着业轮膨胀，无数众生被缓缓挤压至世界边缘，烈焰滋生、四面封堵。众生穷尽逃亡，却无处可避。当共业累积至极致、业轮抵达临界极限，世界便会因业力成熟而自然崩坏。

烈焰席卷天地，粒子溃散、山河焚毁，一期世间彻底终结。

毁灭并非惩罚，而是因缘聚合的必然结果。共业成熟，则世界坏灭；坏灭之后，世间沉寂重置，新一轮懵懂众生再度降生，轮回继续往复。

于此无尽流转之中，绝大多数众生随业浮沉、徒劳挣扎、随坏而灭。

唯有极少数人，放下恐惧、放下求生、放下执着，心安不动。不逃、不执、不逐外境，心念清净，便会触发飞升。金身显、光点环绕、脱离尘界、向上出离，彻底断除此世轮回，不再重来。

玩家为世间旁观者，可撒沙、布火、造境、牵引业轮，成为因缘之一。

你可以干预境遇，但无法主宰因果；你可以创造外缘，但无法替众生解脱。

一切浮沉、毁灭、出离，皆由无数因缘和合而成，万般命运，只可随缘。

游戏本体无任何文字剧情，遵循禅宗「不立文字」，一切深意，交由观者自悟。

## 操作一览

| 操作 | 效果 |
|------|------|
| 左键点击／拖动空白处 | 绘制当前所选元素（沙、水、火、岩浆、油、石、火药、灰烬、植物） |

| 顶部工具栏 | 切换元素、调节画笔粗细、清空世界、手动召唤业轮 |

## 运行与部署说明

### 本地快速运行（零配置）

本项目为纯静态单文件网页，无后端、无依赖、无需编译。下载项目全部文件后，直接双击根目录下的 `index.html` 文件，即可用默认浏览器打开游玩，支持所有主流浏览器。

### GitHub Pages 部署

本项目已通过 GitHub Pages 在线部署：**<https://drhycheung.github.io/SandSamsara/>**

如需自行部署一份：

1. 将本仓库 Fork 至你的 GitHub 账号，或推送你自己的副本
2. 进入仓库页面，依次打开 **Settings → Pages**
3. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**
4. **Branch** 选择 `master`（或 `main`），目录选择 `/ (root)`，点击 **Save**
5. 等待 1–2 分钟构建完成，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

### Vercel 部署

1. 登录 [Vercel](https://vercel.com)，点击 **Add New → Project**
2. 导入本项目的 GitHub 仓库
3. 保持默认配置（Framework Preset 选择 **Other**），直接点击 **Deploy**
4. 部署完成后即可通过 Vercel 分配的域名访问，亦可按需绑定自定义域名

### Nginx / Apache 部署

将项目全部文件上传至服务器站点根目录，无需任何额外配置：

- **Nginx**：放置于 `/usr/share/nginx/html/`（或你自行配置的 `root` 目录）
- **Apache**：放置于 `/var/www/html/`
